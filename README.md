# Ashrafur Rahman - Virtual Assistant Portfolio

A professional portfolio website for **Ashrafur Rahman**, a Virtual Assistant based in Dhaka, Bangladesh. The website presents Ashrafur's services, skills, project examples, blog ideas, contact information, and social links with a modern red-and-green visual identity inspired by the Bangladesh flag.

## Repository Description

Advanced responsive Virtual Assistant portfolio website for Ashrafur Rahman, featuring Home, About, Project, Skill, Blog, and Contact pages with professional branding, project showcases, VA skill highlights, and contact-ready front-end structure.

## Live Preview

Run the project locally and open:

```text
http://localhost:4173
```

## Features

- Professional personal branding for a Virtual Assistant portfolio
- Fully connected pages: Home, About, Project, Skill, Blog, and Contact
- Responsive layout for desktop, tablet, and mobile
- Bangladesh-inspired red and green color system
- Hero section with personal portrait and service highlights
- Virtual Assistant project showcase with realistic portfolio examples
- Skills page focused on freelancing and remote job market needs
- Blog page with original article ideas for remote work and operations
- Contact page with phone, email, address, Facebook, and LinkedIn links
- Contact form that prepares an email draft for client inquiries
- Small Node.js static server for local preview and future backend extension

## Pages

### Home

Introduces Ashrafur Rahman as a Virtual Assistant and highlights core services including inbox management, scheduling, CRM support, research, and client communication.

### About

Explains Ashrafur's work style, virtual assistant capabilities, communication approach, and client support process.

### Project

Includes sample Virtual Assistant projects such as executive inbox organization, lead research CRM setup, e-commerce support templates, travel research, data cleanup, and content calendar support.

### Skill

Highlights important freelancing and job-sector VA skills including email management, calendar scheduling, data entry, lead generation, CRM management, online research, customer support, Google Workspace, Microsoft Office, task management, and confidentiality.

### Blog

Provides original blog concepts about delegation, CRM cleanup, customer support templates, SOPs, and remote work productivity.

### Contact

Displays direct contact details and includes a front-end contact form that generates a mail draft.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Asem758/ashrafur-va-portfolio.git
cd ashrafur-va-portfolio
```

Run the local server:

```bash
node server.js
```

Open the website:

```text
http://localhost:4173
```
